## 3. 功能集与交互（何时追腰 / 何时拉伸 / 供电）

### 3.1 三项能力在本产品上的诚实定义

| 能力 | 本产品口径（对齐上传行程） | 对标意图 | **不做**什么 |
| --- | --- | --- | --- |
| **传感自动追腰** | 入座后，腰靠在上下 **5 cm**、前后 **5 cm**、约 **15°** 动态角包络内由传感闭环微调 | X7 类「少按键跟腰」 | 不做 X7 式 8D 揉捏机芯 |
| **分块动态上背** | 左右上背各 **↑5 / AP5 / ±15°**（共 2×3 DOF）；框 50×57、可升降 5 cm；与腰靠解耦 | Omni「扭身」意图，机构改为分块 3DOF | 不宣称「背板等于传感追腰」 |
| **电机短周期拉伸** | 一键约 **4–6 分钟**，腰靠在前后 **5 cm** 行程内往复（可叠加小角度节拍）；与 Track **互斥** | OmniStretch 类 | 不包装成医疗牵引 |

### 3.2 交互状态机（工程核心）

```
[空座] --入座--> [待机/机械可用]
                 |
                 v
            [追腰 Track]  ← 默认办公模式（低占空比微动）
                 |
        用户按「拉伸」或 App/臂键
                 v
            [拉伸 Stretch]  ← 互斥：暂停追腰闭环，跑开环曲线
                 |
            结束 / 用户中止 / 离座 / 过流
                 v
            [再捕获 Re-acquire] → 回 [追腰 Track]
```

| 模式 | 何时运行 | 用户要做什么 | 电机行为 |
| --- | --- | --- | --- |
| **Track（默认）** | 座压有效 + 倾仰未入「大躺暂停区」+ 电量充足 | 几乎不用管；可设轻/中/强贴合力 | 腰靠在 5 cm AP / 5 cm 高度 / ~15° 包络内闭环小步；死区防抖 |
| **Stretch** | 用户显式触发；建议坐直、双脚着地 | 一键开始；可随时停 | 开环往复于前后 **5 cm**；**禁止**同时 Track |
| **Manual Override** | **臂键**（装在扶手附近的按键，非扶手电动）点动腰深、腰高 | 立刻改目标；短暂抑制自动 | 跟手点动 |
| **Degraded** | 低电 / 传感故障 / 过温 | 提示；气杆座高、倾仰、被动背形变仍可用 | 停电机 |

**倾仰联动（对齐底盘档）：** 办公常用 **90° / 100°** 保持 Track；进入 **130°** 起降低追腰增益或持位；**160°** 大躺建议 **暂停 Track 持位**，避免硬顶。Stretch 建议限制在 90°–100° 附近；大角度时 UI 提示先回正。若实现「任意角度锁定」，暂停阈值可按倾仰角连续映射，而非仅四档。【实现细节标为工程选择，档位本身来自上传】

### 3.3 电源与电池

| 项 | 方案 |
| --- | --- |
| 主路径 | **内置可充电池 + USB-C** |
| 容量目标 | 约 **4000–5000 mAh**【假设】：Track 占空比 + 多轴（腰/上背）高于 Omni 常见 2200–3000 mAh |
| 没电时 | 气杆座高、机械倾仰、动态背被动形变可用；电机追腰/追背/拉伸停 |
| 可选线充 | 桌下 USB-C PD 常接 |
| 不做 | 整椅电动升降（座高仍气杆 **45–55 cm**） |

## 4. 机构与传感草图（概念级；行程对齐上传）

### 4.1 为什么市面难「三项硬叠」（tradeoff）

| 冲突 | 说明 |
| --- | --- |
| **传感 vs 柔性/动态上背** | 上背 15° 动态追背会改力分布；腰区传感须装在**腰靠硬背板**，与上背解耦。 |
| **闭环持位 vs 开环往复** | Track 轻静小步；Stretch 在同一 **5 cm** AP 行程内大幅往复 → **分时互斥**。 |
| **多自由度堆叠** | 上背 **左右各 3DOF** + 腰靠轴系；扶手为 **4D 纯机械**（无电机）。上背优先弹性包络，电机化另立项。**放弃机芯按摩**。 |
| **成本 / 噪音 / 保修** | 电子质保与电池续航压力大于纯按键 Omni。 |

结论：合脊 TF-1 仍用 **「腰托滑架与动态上背解耦 + Track/Stretch 互斥」**；上传行程把「前后 5 cm / 15° 追腰·追背」写成可核对的包络，而不是营销空话。

### 4.2 推荐架构（TriFlex，尺寸按源文）

1. **背框 + 分层**  
   - 靠背框 **50×57 cm**，整体可升降 **5 cm**。  
   - **上背左右分块**（外包络约 50×34 cm）：左/右各一块，**每块 3 自由度**——升降 **5 cm**、前后 AP **5 cm**、节距 **±15°**；左右独立以支持扭身非对称贴合。  
   - 实现优先级：每块以 **受控弹性 + 阻尼 + 硬限位** 落在 3DOF 包络内；若电机化则每侧最多 3 轴，Stretch 时锁定。**不承担**腰托主推力。

2. **独立腰靠滑架（48×24 cm）**  
   - AP **5 cm**、高度 **5 cm**、约 **15°** 动态节距；压力条带贴腰靠硬背。  
   - Stretch 复用 AP 推杆，开环往复于 5 cm 内。  
   - 初始几何：相对坐垫最外缘 **~42 cm**；与坐垫间隙 **~3 cm**。

3. **头枕（36×20 cm）**  
   - 升降 **8 cm**；外轴翻 **45°**、内轴翻 **90°**；**前后行程 TBD**（乱码，定点前补测/补需求）。

4. **坐垫**  
   - 前后滑动 **4 cm**；**6°** 跷跷板微摆（跟倾仰或独立枢轴——实现二选一，原型验证）。

5. **传感与电控**  
   - 座压占用；腰区 2–4 区压力；背框倾仰角；电机电流/端点。  
   - MCU 强制 Track ⊥ Stretch；左右上背可非对称；Stretch 时 **左右上背锁定或降增益**。  
   - 无摄像头追腰。

6. **安全**  
   - 力帽、离座即停、Stretch 长按启动、过流/过热；连续 Stretch 冷却间隔【假设 ≥10 min】。  
   - 非医疗器械。

```
[头枕 36×20 | ↑8cm | 外翻45°/内翻90° | AP=TBD]
        |
[上背左 | ↑5 AP5 ±15°] [上背右 | ↑5 AP5 ±15°]  ===挂==>  [靠背框 50×57 | ↑5cm]
        |
[腰靠 48×24 | ↑5cm | AP 5cm | ±15° 追腰/Stretch]  <== 推杆+传感
        |  间隙 ~3cm
[坐垫 | 前后4cm | ±6° 微摆] ---- 初始外缘距腰靠外缘 ~42cm
[4D 纯机械扶手]  [底盘 90/100/130/160° + 任意锁【目标】]
[气杆座高 45–55cm]  [≥3" 透明橡胶双轮]
         \___ USB-C 电池 ___/
```

## 7. 与 LiberNovo Omni、黑白调 X7 的差异

| 维度 | LiberNovo Omni 电动系 | 黑白调 X7 | **合脊 TF-1** |
| --- | --- | --- | --- |
| 自动追腰 | 机械随动 + **按键**电机腰深（常见约 50 mm） | 传感 AI 追腰强 | 传感闭环；腰靠 AP/高度各 **5 cm** + **15°**（上传） |
| 动态背 | FlexFit 8 面板典型 | 非 FlexFit | **左右上背各 3DOF**（↑/AP/±15°）分块扭身 |
| 放松 | OmniStretch 往复 | 机芯按摩+热敷 | **5 cm** 行程内短周期拉伸；无机芯 |
| 倾仰 | 常见约至 160°（Pro 等） | 公开约 140° 量级 | **90/100/130/160°** + 任意锁目标（上传） |
| 座高 | 气杆（型号各异） | 气杆 | **45–55 cm**（上传） |
| 供电 | 电池 USB-C | 多为插电向 | 电池为主 |

**一句话：** Omni 缺真传感追腰；X7 缺分块动态背+OmniStretch 式拉伸；TF-1 为腰靠闭环 + **左右上背各 3DOF** + Track/Stretch 互斥；扶手为 **4D 纯机械**。

## 8. 开放风险与验证计划（原型）

### 8.1 主要风险

| 风险 | 表现 | 缓解 |
| --- | --- | --- |
| 头枕 AP 未定 | 160/185 cm 两端头枕前后不够 | 补齐源文乱码项后再开模；试坐矩阵含头枕前后 |
| 42 cm / 3 cm 几何 | 与滑动 4 cm、微摆 6° 耦合后坐感两极化 | 工装检具锁定初始位；两端身高试坐 |
| 上背左右各 3DOF + 腰 | 干涉、夹手、左右耦合/振荡 | 中缝防夹；Stretch 锁左右上背；弹性优先 |
| 任意角锁定 | 成本/可靠性高于四档棘轮 | MVP 先四档可靠，任意锁作 Pro 目标 |
| 多电机噪音续航 | 七自由度+双追 | 死区、占空比、分时励磁 |
| 期待管理 | 「医疗三合一」话术 | 仅工学语言；禁伪专利/伪临床 |

### 8.2 原型验证清单

1. 腰靠台架 + **左/右上背各 3DOF** 台架：行程、非对称扭身、中缝夹手、寿命。  
2. 初始几何检具：外缘距 **42 cm**、间隙 **3 cm**，坐垫滑 4 cm 后仍可接受。  
3. Track/Stretch 互斥与声压/顶力（不编造 N 与 dB 实测值）。  
4. 倾仰四档 +（若有）任意锁：130°/160° 下 Track 暂停策略。  
5. 人因：身高 **160 / 172 / 185 cm**，含头枕（AP TBD 用可调工装扫参）。  
6. 脚轮：≥3" 透明橡胶双轮滚动与地板痕迹。  
7. 对比盲测：Omni 电动 vs X7 vs TF-1 原型。

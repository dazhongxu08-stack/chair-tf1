# 合脊 TF-1 方案审查：不合理点与优化建议

> 对照：`chair-product-concept.md`、`tf1-mechanical-structure-analysis.md`、机构简图。  
> 性质：**设计评审**，非否定整体方向。优先级：P0 阻塞量产开模 / P1 强影响体验与成本 / P2 可后置。

---

## 总评（先读）

**方向合理：**「腰靠传感闭环 + 分块上背 + Stretch 与 Track 互斥」清晰。

**2026-09-23 产品决策（已写入概念/力学稿）：**
- **不做 7D 扶手 → 定 4D 纯机械手动（无电机、不自动）**
- **上背左右分块，每块 3 自由度**（↑5 / AP5 / ±15°）

**仍须盯紧：** 头枕 AP TBD、42/3 cm 运动学、Stretch 力帽、上背 2×3DOF 若全电机化的成本与振荡（基线仍建议弹性实现包络）。

## P0 — 必须先改 / 先闭合

### 1. 头枕前后行程仍是 TBD

- **问题：** 160–185 cm 两端差异大，头枕只有升降+双轴翻、**没有前后**，高个/深坐时头枕常「够不着」或顶后脑。开模后改极贵。  
- **优化：** 人因扫参定 **前后行程带**（常见办公椅约 30–60 mm 量级，**须实测后写入**，本文不拍数）；未闭合前 **禁止背框/头枕开模**。

### 2. 「42 cm 外缘距 + 3 cm 间隙 + 坐垫滑 4 cm + 微摆 6°」耦合未做运动学闭合

- **问题：** 坐深有效范围随滑动/微摆/倾仰变化；185 cm 与 160 cm 对腘窝间隙、腰托高度需求相反，单初始几何容易一端顶腿、一端腰空。  
- **优化：** 做 **2D 侧视连杆/包络图**（CAD）：倾仰 90–160° × 坐垫滑全行程 × 腰靠 AP/高度极限；输出「禁止区」与默认标定表（按身高分档预设）。

### 3. 腰靠同时具备 ↑50 / AP50 / ±15°，与 Stretch 复用同一 AP —— **自由度冗余且控制难**

- **问题：** AP 与节距在接触力学上高度耦合（顶腰可用「前移」或「仰角」近似实现）；三轴全电机化 → 噪音、线束、成本、振荡。Stretch 大幅往复时节距若自由，易「啃垫/打滑」。  
- **优化（MVP）：**  
  - **只电机化：AP（Track+Stretch）+ 高度（低频手动或入座一次电机）**  
  - **节距：弹簧+阻尼+硬限位 ±15°**（力学稿已写，应升为基线，不再「可选」）  
  - Stretch 时 **锁高度、锁节距包络中位**

### 4. Stretch 力帽 180 N 与「非医疗」叙事张力大

- **问题：** 180 N 局部顶腰对瘦体/骨质疏松/术后人群风险高；开环 4–6 min 往复若卡住衣物/皮肤更危险。纸面力帽不等于体感安全。  
- **优化：**  
  - 默认力帽先落到 **100–140 N【待人因】**；强档需二次确认  
  - Stretch：**双手离开键盘检测 / 座压稳定 / 倾仰≤100° / 双脚着地提示**；周期改 **短时多段**（如 30–60 s × 可停）而非默认 5 min 连续  
  - 文案禁止「牵引/治疗」；说明书加禁忌人群

### 5. 电池 4000–5000 mAh 标称与「多轴 Track」不匹配口径

- **问题：** mAh 未写电压平台；Omni 对比用 mAh 不科学。Track 若频繁闭环，待机电流与保持电流才是杀手，单次 Stretch 功耗反而小（力学稿已指出）。  
- **优化：** 改写为 **Wh + 日场景续航**（如：Track 中档 8 h/天 × N 天）；给出 **休眠策略**（入座后 30–60 s 收敛后几乎零励磁，仅压力越死区才动）。未验证前不要对外报「一个月」。

## P1 — 强烈建议改

### 6. 上背「左右各 3DOF」——扭身更好，但轴数风险上升

- **现状：** 已定左/右分块，每块 ↑5 / AP5 / ±15°。  
- **风险：** 若 6 轴全电机，噪音/成本/振荡显著；中缝夹手。  
- **优化：** **弹性+阻尼实现 3DOF 包络**为基线；电机化分阶段；中缝防夹与非对称疲劳按 1.3× 校核。

### 7. 靠背框整体再升 50 mm + 上背升 50 mm + 腰升 50 mm —— **三重高度调节过剩**

- **问题：** 用户不知调哪一个；装配公差叠加导致传感标定漂移。  
- **优化：** 保留 **框升（手动）+ 腰高（电机低频）**；砍上背升降。UI 给「身高一键预设」而不是三套旋钮。

### 8. 扶手 — **已定 4D 纯机械，关闭 7D / 关闭电动**

- 扶手仅手动机械调节；**不装电机、不自动跟随倾仰或坐姿**。  
- 腰托/Stretch 的电控用**臂侧按键**，与扶手自由度机构分离。

### 9. 「任意角度锁定」与四档棘轮并行 —— 目标漂移

- **问题：** 任意锁（摩擦/液压）可靠性、手感、认证与四档不是同一套模具。概念稿已说 MVP 可砍，但规格表仍并列，易在采购/开模时被当成必做。  
- **优化：** 规格表拆成 **MVP 必达 / Pro 目标**；任意锁从「规格」降为「路线图」。

### 10. 倾仰 160° + 电池椅 + 同步机构 —— **倾覆与充电线**

- **问题：** 大躺时重心后移；桌下常接 USB-C 时线缆绊脚、扯接口。透明脚轮在硬地板制动差。  
- **优化：** 倾覆试验按国标/BIFMA 做 **160°+脚踏（若有）**；提供 **无线为主 + 磁吸充电座**；大躺档增加 **回正阻尼**；脚轮考虑带止动或升级承重。

### 11. Track「默认常开」体验可能适得其反

- **问题：** 用户前倾打字时腰托主动前顶，易被吐槽「推着走」；压力传感在泡沫下易漂移、温度敏感。  
- **优化：** 默认改为 **「入座自动贴合一次 → 持位」**；「连续追腰」作高级选项。增加 **温度补偿/定期零点**；双通道传感投票防单点漂移误顶。

### 12. 力学估算里丝杠扭矩与「推荐电机扭矩」量级差过大

- **问题：** 纸面 \(T_\mathrm{screw}\approx0.23\,\mathrm{N\cdot m}\)，文中又建议 0.8–1.2 N·m 输出——说明偏载/摩擦模型不足，选型边界模糊。  
- **优化：** 台架测 **实测推杆力–电流–温升** 曲线再定电机；按 **堵转力 / 额定力 / 占空比** 三维选型，删掉易误导的「纯理想丝杠算式」作对外依据。

### 13. 自重 28–35 kg 与「家用搬运 / 电梯」冲突风险

- **问题：** 电机+导轨+7D 扶手+大电池，35 kg 已偏重；再涨就难网购「送货上门无安装」话术。  
- **优化：** 设 **自重上限目标（如 ≤32 kg）**；铝/塑分配；电池可抽换模块，避免整椅报废。

## P2 — 应规划但可后置

### 14. 认证与锂电池运输未展开

- 家具强度 + UN38.3/航空运输 + 电器安规（含发热、夹手）要单独立项；「电池椅」售后比插电椅重。  
- **优化：** 认证清单与地区（国标 / BIFMA / CE）进路线图；电池可拆卸降低整椅运输等级。

### 15. 噪音目标 Track ≤35 dB(A)@1 m 偏紧

- 丝杠微步很难长期稳定低于安静办公室底噪很多；未写测距与 A 计权条件时不宜写进卖点。  
- **优化：** 对内作工程目标，对外改「安静办公场景下不明显打扰」类定性，或给出对比竞品的相对值。

### 16. 坐垫「跷跷板 6°」与倾仰同步定义不清

- 跟倾仰还是独立枢轴未定，两种机构对腘窝压力完全不同。  
- **优化：** 原型 A/B：仅同步倾仰 vs 独立微摆；选一，避免双机构。

### 17. 成本带 ¥4500–6200 与功能野心可能倒挂

- 若 MVP 不砍轴，BOM ¥1200–1800【假设】可能偏低（7D+双动态+传感+电池）。  
- **优化：** 做 **功能–BOM 矩阵**：每砍一轴省多少；保证「传感追腰 + Stretch」两件套不被扶手/任意锁挤掉。

### 18. 软件/App 可选但状态机复杂

- Track/Stretch/再捕获/大躺降增益需要可测的状态覆盖；App 不是必须，却增加版本碎片。  
- **优化：** 一期 **臂键 + 指示灯** 跑通状态机；App 只读电量/模式。

## 建议的 MVP 收敛（相对当前概念稿）

| 模块 | 当前概念 | 建议 MVP |
| --- | --- | --- |
| 腰靠 | ↑ + AP + ±15° 电机化倾向 | **AP 电机 + 高度低频；节距被动** |
| 上背 | ↑ + AP + ±15° | **左/右分块，每块 3DOF**；**弹性实现包络**（电机另立项） |
| Stretch | 4–6 min @≤180 N | **短时多段 @≤120–140 N；强约束姿态** |
| Track | 默认连续追 | **入座贴合后持位；连续追为选项** |
| 扶手 | 7D | **4D 纯机械（已定，无电机）** |
| 倾仰 | 四档+任意锁 | **仅可靠四档** |
| 头枕 | AP TBD | **先闭 AP 再开模** |
| 电池 | 报 mAh | **报 Wh + 场景续航 + 休眠策略** |

保留差异化叙事：**真传感贴腰 + 短时拉伸 + 左右上背各 3DOF（弹性包络）+ 4D 纯机械扶手**。

## 仍合理、建议保留的部分

- Track ⊥ Stretch 互斥与大躺暂停 Track  
- 腰硬背装传感、与上背解耦  
- 没电可坐（气杆/倾仰/被动背）  
- 无机芯按摩（降故障面）  
- 导轨双轨抗偏载、倾仰忌短力臂拉杆等力学提醒
